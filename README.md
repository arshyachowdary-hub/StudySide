# StudySide Web App
Files: index.html, about.html, app.html, stories.html, styles.css, app.js.
Open index.html directly in a browser. No npm/build step is required.
Tailwind CSS and Google Fonts load through CDN links.
The App page includes an academic planner, priorities, deadlines, estimated time,
smaller assignment steps, wellbeing check-in, Bad Day Mode, prototype AI assistant,
trusted-person list, and weekly reflection. Browser localStorage is used for the demo.
The AI is intentionally rule-based so the files work locally. A production AI feature
should use a secure backend and never expose a private API key in client-side JavaScript.
Image placeholders are accessible and can be replaced with real <img alt="..."> elements.
